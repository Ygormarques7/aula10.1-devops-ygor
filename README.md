# aula10.1-devops-ygor

Repositório - atividade prática da Aula 10.1 de DevOps I — Univértix 2026.

## Sobre

Aqui estão os arquivos e configurações feitas durante a aula prática de GitHub.
O foco foi aprender a configurar SSH, MFA e trabalhar com repositórios remotos.

## Conteudo

- Criação do repositório no GitHub
- Geração de chave SSH Ed25519
- Configuração do remote via SSH
- Ativação do MFA na conta
        -  FALTA FAZER -
- Adição da Deploy Key do professor 

## Comandos 

```bash
ssh-keygen -t ed25519 -C "email@exemplo.com"
ssh -T git@github.com
git remote -v
git push / git pull
```
